# Where AI was used in this project

## Data folder

No AI was used because that directory is simply for storage of all data.

## Docs folder

AI was fed information and design decisions for the project and it formatted an easy to reach structure for the md files.

## Migrations folder

AI scaffolded Alembic (`alembic init migrations`), wired `migrations/env.py`
to the SQLAlchemy models and `DATABASE_URL` (python-dotenv), generated the
first autogenerated `create ai_call_log` revision, and retired the old
`init_db.py`/`create_all()` path. Human reviewed and ran the migration.
AI also autogenerated the Phase 3 revision that adds `images`, `posts`,
`image_metadata`, `image_vectors`, and `post_vectors`.

## Scripts folder

AI was used for debugging purposes and for research.

## Src folder

The src folder consists of many other different folders which is why the disclosure of AI use in this folder will handled individually for each folder included.

### Api folder

AI helped write documentation (docstrings) in each of the files in the route folder but was not used to write any code. Dependencies.py and main.py had no AI use. Schemas.py was delegated to AI since it is alot of repetitive, easy to write code. The file was then reviewed by a human. 

### Db folder

Models.py was written with a good amount of help from AI by instructing it to define all the classes with provided parameters. AI was used for debugging in session.py.

### Matching folder

AI was not used for anything in this folder

### Telemetry folder

AI helped write call_logger.py through discussion and iterative improvements.

### Vision folder

AI helped create the schema.py file because it was tedious to create (50 subjects as enums). All other files had no AI use for writing code, just debugging and fixing unexpected behavior.

## Tests folder

All tests have been generated using AI but under close supervision.

## Miscellaneous files

This category covers all files that are not in any folder such as README.md and .env.example. Only the .gitignore and LICENSE files were automatically generated by GitHub itself. The files alembic.ini and README.md were written with the help of AI by having a human direct it on what the contents of these files should be. All other miscellaneous files had no AI involvment.
