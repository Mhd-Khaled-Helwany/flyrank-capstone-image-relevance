# Where AI was used in this project

## Data folder

No AI was used because that directory is simply for storage of all data.

## Docs folder

AI was fed information and design decisions for the project and it formatted an easy to reach structure for the md files.

## Migrations folder

No usage of AI.

## Scripts folder

AI was used for debugging purposes and for research.

## Src folder

AI helped create the schema.py file because it was tedious to create (50 subjects as enums). All other files had no AI use for writing code, just debugging and fixing unexpected behavior.

## Tests folder

All tests have been generated using AI but under close supervision.
